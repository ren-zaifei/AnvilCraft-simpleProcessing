# AnvilCraft SimpleProcessing

[English](#english) | [中文](#中文)

---

## English

**AnvilCraft SimpleProcessing** is a [NeoForge](https://neoforged.net/) addon mod for [AnvilCraft](https://github.com/Anvil-Dev/AnvilCraft) that adds more advanced anvil-powered processing workstations.

### Blocks

| Block | Description |
| --- | --- |
| **Advanced Stamping Platform** | Drops an anvil on it to stamp items into new forms. Outputs items in the direction it faces. |
| **Advanced Crushing Table** | Drops an anvil on it to crush items. Supports AnvilCraft's Item Crush recipes. |
| **Advanced Unpack Table** | Drops an anvil on it to unpack/decompose items. Supports AnvilCraft's Unpack recipes. |
| **Advanced Mesh Table** | Drops an anvil on it to sift items through a mesh. Supports AnvilCraft's Mesh recipes. |

### Features

- Auto-pickup items dropped from above
- Right-click to insert or extract items
- Item-based input, entity-based output (no GUI)

### Dependencies

| Dependency | Required |
| --- | --- |
| [Minecraft](https://www.minecraft.net/) 1.21.1 | ✅ |
| [NeoForge](https://neoforged.net/) 21.1+ | ✅ |
| [AnvilCraft](https://github.com/Anvil-Dev/AnvilCraft) | ✅ |
| [JEI](https://www.curseforge.com/minecraft/mc-mods/jei) | ❌ Optional |

## 中文

**AnvilCraft SimpleProcessing** 是一个基于 [NeoForge](https://neoforged.net/) 的 [AnvilCraft](https://github.com/Anvil-Dev/AnvilCraft) 附属模组，添加了更多加工物品的高级工作台。

### 添加的方块

| 方块 | 说明 |
| --- | --- |
| **高级冲压平台** | 铁砧砸落时执行冲压配方，产物从方块正面弹出。 |
| **高级粉碎台** | 铁砧砸落时执行粉碎配方（物品粉碎）。 |
| **高级解包台** | 铁砧砸落时执行解包配方（拆解物品）。 |
| **高级筛网台** | 铁砧砸落时执行筛网配方（筛分物品）。 |

### 特性
- 可自动吸取上方的掉落物
- 可进行交互，拿取/放入
- 无实体输入，有实体输出
